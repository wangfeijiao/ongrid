## 需要处理的问题

### 1. 10.7.30.32 —— 磁盘 100% 满，无法安装

```
/dev/vda1  100G  100G  0  100%  /
```

edge 完整包解压后约 640 MB，磁盘无空间则写入失败。需先清理该机磁盘，之后执行：

```bash
python deploy.py --phase install --seed 10.7.30.13 --only 10.7.30.32
```
