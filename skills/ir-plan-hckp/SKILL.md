# 安全事件响应

本技能为**免费**知识型技能：提供方法论与模板，不涉及付费服务。

## 适用场景
发生入侵/泄露要按流程处置。

## 核心方法
先遏制扩散，再根除与取证。

## 标准步骤
1. 确认事件与范围
2. 隔离受影响资产
3. 取证与溯源
4. 清除后门与加固
5. 复盘并补监控

## 可直接套用的模板
```
发现→遏制(隔离)→根除(清后门)→恢复→复盘
```

## 常见错误
- 不隔离致扩散
- 不清后门
- 不取证

## 自检清单
- [ ] 先遏制
- [ ] 已取证
- [ ] 已复盘
