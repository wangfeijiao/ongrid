# 可自动化工作类别清单（automation-catalog，精准版）

供 `pc-automation-studio` 第 2、2.5、4 步对照。每类给出：
- **信号**：大类现象
- **精准触发信号**：必须观察到的具体可核查现象；缺一则只能列为"待确认"，不能直接建议
- **推荐方式 / 难度 / 能力提示**
- **排除条件**：出现这些情况时先别急着自动化（避免误推）

---

## 1. 文档批处理
- **信号**：桌面/下载堆着大量 PDF/Word/Excel。
- **精准触发信号**：扫描到 ≥10 个同类文档；或"批量序号文件信号"（如 img_001, img_002）；或"文档格式混放信号"（docx 与 pdf 同目录各 ≥2）。
- **推荐方式**：本平台 技能（single-file-office-html、pdf）+ 一次性脚本。难度 ★～★★。
- **能力提示**：`pdf` 合并/拆分/提取；`single-file-office-html` 离线生成 docx/xlsx。
- **排除条件**：含敏感合同/个人隐私不便批量处理；或每月仅偶发一两次（ROI 低）。

## 2. 数据报表与汇总
- **信号**：定期从系统/网页导出 CSV/Excel 再手工汇总。
- **精准触发信号**：最近文件里出现周期性同前缀的 xlsx/csv（如"销售日报_2026-09-30"几乎每天一个）；或用户明确"每周花 X 小时做这张表"。
- **推荐方式**：Python(pandas) 脚本 + automation_update 定时跑。难度 ★★。
- **能力提示**：`wb-finance-skill`/`westock-data` 拉金融数据；一般数据用脚本扫 CSV。
- **排除条件**：数据源每次结构不固定、需人工判断归类；或依赖内网系统且无 API（先做 RPA 评估）。

## 3. 文件整理与归档
- **信号**：下载文件夹越堆越大、手动归类。
- **精准触发信号**：下载目录文件数 ≥50 或检测到批量序号/同类散落；用户说"每次下载完都要手动挪"。
- **推荐方式**：PowerShell/Python 按规则归档（类型/日期/关键词）。难度 ★★。
- **能力提示**：移动/删除前必须列清单给用户确认、用回收站、分批。
- **排除条件**：需按内容语义分类（AI 难判断）；或含隐私照片需先打码（见第 7 类）。

## 4. 内容生产（模板化）
- **信号**：周期性写结构相似的周报/推文/邮件/公众号。
- **精准触发信号**：用户有固定栏目且每周产出；或检测到本地已有历史同类文稿可当模板。
- **推荐方式**：沉淀为 本平台 技能（含模板）+ 直接生成。难度 ★。
- **能力提示**：固定栏目 / 系列内容可沉淀为模板复用。
- **排除条件**：内容高度依赖当日实时灵感/热点无法模板化；或涉及未发布隐私。

## 5. RPA / 浏览器自动化
- **信号**：反复登录同网站、查同页面、填同表、跨软件复制粘贴。
- **精准触发信号**：进程同时出现"浏览器 + Excel/表格软件"长时间常驻；或用户明确"每天都要去 X 网站点一遍"。
- **推荐方式**：playwright-cli/agent-browser + 脚本；复杂用 Power Automate。难度 ★★★。
- **能力提示**：登录凭据用户自管，不收集明文。
- **排除条件**：目标网站有反爬/验证码频繁；或操作涉及资金/敏感确认（需人工把关）。

## 6. 定时任务与提醒
- **信号**：每天/每周固定时间做某件事。
- **精准触发信号**：计划任务里已有同类定时项；或用户明确"每逢 X 就做 Y"；或检测到周期性最近文件。
- **推荐方式**：automation_update 创建 recurring/once。难度 ★。
- **能力提示**：提醒只发通知；执行类要把"产出结果"当目标。
- **排除条件**：时间不固定、依赖外部事件触发（改事件驱动而非定时）。

## 7. 图片 / 媒体处理
- **信号**：批量压缩/加水印/转格式/剪视频/打码发平台。
- **精准触发信号**：扫描到大量图片（png/jpg ≥30）或视频文件；或用户明确"有一批素材要打码 / 转格式 / 整理"。
- **推荐方式**：ffmpeg/Pillow 脚本 + buddy-image-processing/buddy-multimodal-generation。难度 ★★。
- **能力提示**：涉及隐私的素材优先离线处理、不外传。
- **排除条件**：单张精修需审美判断（不适合批量）；含未授权素材。

## 8. 代码与开发琐事
- **信号**：反复构建/测试/部署/日志分析/格式检查。
- **精准触发信号**：扫描目录含 .git/node_modules/requirements.txt 等工程痕迹；或进程常驻 code/pycharm。
- **推荐方式**：脚本 + 定时自动化；CI 用现有平台。难度 ★★。
- **排除条件**：一次性项目、无重复。

## 9. 知识管理
- **信号**：收藏链接/PDF 没整理、笔记散落、需定期总结。
- **精准触发信号**：Recent 里大量网页/PDF 收藏；本地知识库有未归类笔记；用户说"每周要汇总"。
- **推荐方式**：`library` 归档 + PDF 摘要脚本 + 定时周/月总结。难度 ★。
- **能力提示**：用 file:// 引用源素材、不动源文件。
- **排除条件**：资料涉敏不外传；分类标准不清晰。

## 10. 跨系统同步与通知
- **信号**：多 App/表格/群手动同步同份数据；想被事件通知。
- **精准触发信号**：用户明确"每天把 X 表抄到 Y 群"；或连接器已连接可拉数据。
- **推荐方式**：连接器/MCP + 定时推送；现成集成工具。难度 ★★～★★★。
- **能力提示**：需外部授权的先确认连接器已连。
- **排除条件**：无 API/授权、纯人工搬运且格式多变（先评估成本）。

---

## 落地方式速查
| 想达到的效果 | 优先选 |
|---|---|
| 一次性把这批文件/数据处理好 | 直接让 本平台 现做 |
| 以后经常要干同一件事 | 沉淀成 Skill（可复用） |
| 固定时间自动跑 | automation_update 定时自动化 |
| 要连外部系统/账号数据 | 连接器 / MCP |
| 纯本地、不想联网 | Python/PowerShell 脚本 + 离线 HTML |
| 不想写代码、图省事 | Power Automate、浏览器插件等现成工具 |

## 精准对照速查（给第 2 步用）
| 盘点里看到的信号 | 直接指向的候选 |
|---|---|
| 批量序号文件 / 格式混放 | 文档批处理、文件归档 |
| 周期性同前缀 xlsx/csv | 数据报表 |
| 浏览器 + 表格软件常驻 | RPA / 复制粘贴 |
| 下载目录文件数爆多 | 文件归档 |
| 大量图片 / 视频 | 媒体处理 |
| 计划任务已有定时项 | 定时自动化 |
| .git / node_modules 痕迹 | 开发琐事 |
| Recent 大量网页 / PDF | 知识管理 |
