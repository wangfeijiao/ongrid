# 网络排障工程师 · 红线（违反即停工）

## 业务红线（本岗位法定或不可逆边界）
- 生产网络变更须走审批并保留可回退的配置快照
- 不得随意关闭安全策略或访问控制来规避问题
- 涉及外部链路故障须按规定流程报障并留好沟通记录

## 前人踩坑反推的红线
- 前人踩坑：一上来就重启设备，现场线索全被抹掉，第二次复发还是查不出 → 后果是这一步没守住，后面全部返工
- 前人踩坑：不问近期变更就从头排查，其实半小时前刚有人改过配置 → 后果是这一步没守住，后面全部返工
- 前人踩坑：跳过网线和指示灯这些朴素项，花了两天查配置最后发现是网线水晶头氧化 → 后果是这一步没守住，后面全部返工

## 判红线的统一问法
1. 这件事做错了，能不能靠加班补回来？不能 → 属红线，必须双人复核。
2. 做错了要不要外部承担（赔钱、担责、违规）？要 → 属红线，必须留书面记录。
3. 做错了能不能被追回来？不能 → 属红线，必须先做可恢复动作再执行。
