## 适用场景
上线前不知能否扛住。

## 核心方法
梯度加压看拐点，禁压生产高峰。

## 标准步骤
1. 定目标 TPS/RT/错误率
2. 造压测数据与环境
3. 梯度加压找拐点
4. 观测资源与错误
5. 留余量与扩容建议

## 可直接套用的模板
```
目标：RT<200ms 错<0.1%｜梯度加压→拐点→留30%余量
```

## 常见错误
- 直压生产
- 只看均值
- 无资源观测

- [ ] 非生产
