# 可观测性工程师 · 红线（违反即停工）

## 业务红线（本岗位法定或不可逆边界）
- 告警不得因噪声而整体静默导致真实故障被漏报
- 日志采集须避免记录明文密码、令牌与个人敏感信息
- 不得因监控开销影响生产业务的稳定性

## 前人踩坑反推的红线
- 前人踩坑：把所有能想到的指标全采集了，结果没人看得过来还得付不少存储费 → 后果是这一步没守住，后面全部返工
- 前人踩坑：只有日志没有链路，一个跨服务的问题要翻七八个系统的日志 → 后果是这一步没守住，后面全部返工
- 前人踩坑：告警一到半夜就响，响了也没人处理，最后大家集体设置屏蔽 → 后果是这一步没守住，后面全部返工

## 判红线的统一问法
1. 这件事做错了，能不能靠加班补回来？不能 → 属红线，必须双人复核。
2. 做错了要不要外部承担（赔钱、担责、违规）？要 → 属红线，必须留书面记录。
3. 做错了能不能被追回来？不能 → 属红线，必须先做可恢复动作再执行。
