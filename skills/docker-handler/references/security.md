# 安全策略（docker-handler）

本文件为高风险技能的本地安全基线，所有操作须遵守以下门禁。

## 风险分级

- 本技能风险等级：**高（可操作容器与镜像）**。
- 动作分级：
  - L0 只读/列举：可直接执行。
  - L1 读写个人数据/外部账号：先列影响面，关键写操作确认。
  - L2 对外发声/改账号状态：逐条取得明确同意。
  - L3 资金/交易/凭据/不可逆：逐项单独授权，生产先沙箱验证。

## 通用铁律

1. 绝不把密钥/令牌写入技能文件、命令行参数或对话明文。
2. 凭据通过环境变量或密钥引用（如 `op://`）注入。
3. 前置依赖未就绪时**停下报告**，不回退到让用户粘贴明文。
4. 生产/付费/影响他人的动作先做样本验证。
5. 操作后回报状态与异常止损步骤，不静默吞错。

## 事故处置

- 怀疑凭据泄露：立即吊销并轮换，记录时间线与影响范围。
- 误发/误改：第一时间回滚并通知相关方。
