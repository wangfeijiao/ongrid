## 适用场景
全量发布怕出大面积故障。

## 核心方法
小流量先行，指标无异常再放量。

## 标准步骤
1. 选灰度维度（比例/用户/区域）
2. 放 1-5% 观察核心指标
3. 设自动回滚阈值
4. 分批放量至 100%
5. 全程监控

## 可直接套用的模板
```
1%→5%→20%→50%→100% 每步看错误率/RT
```

## 常见错误
- 直接全量
- 无回滚阈值
- 不看指标

## 自检清单
- [ ] 有灰度
- [ ] 有回滚
- [ ] 看指标
