# 监控告警分级

本技能为**免费**知识型技能：提供方法论与模板，不涉及付费服务。

## 适用场景
告警太多没人看。

## 核心方法
按影响面与紧急度分级路由。

## 标准步骤
1. 定义 P0-P3 标准
2. P0 电话/P1 群/P2 工单/P3 忽略
3. 去重与收敛
4. 定期清无效告警
5. 周复盘误报

## 可直接套用的模板
```
P0电话 P1群@ P2工单 P3周报
```

## 常见错误
- 全 P0 致麻木
- 不收敛轰炸
- 无效不清

## 自检清单
- [ ] 分级清晰
- [ ] 路由到人
- [ ] 定期清
