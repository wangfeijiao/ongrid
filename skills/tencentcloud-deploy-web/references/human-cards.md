# 人工卡模板

用法：选路径后，把这条路径需要人做的卡**合并成一张**一次发出（每次等人都可能是几小时）。
人回"好了"后，按卡末尾的「agent 验证」逐条确认，只对没过的项再出卡。

---

## C0 首次接入：网页向导（默认方式）

agent 在后台运行 `python {baseDir}/scripts/setup.py`，同时对用户说一句：

```
我需要连上你的腾讯云账号才能帮你部署。我在你电脑上打开了一个设置页面，照着做大约 5 分钟，只需要做一次。
页面最上面写清楚了我能做什么、不能做什么（比如我花不了你的钱，也删不了你的服务器）。
最后一步要填两串密钥，直接填在那个页面里就行，不要发给我。
（页面没有弹出来的话，点这个链接：<SETUP_URL>）
```

安全说明、注册和实名、建策略（带一键复制）、建子用户的勾选项、密钥输入框，**全部在页面里**。
如需修改文案，改 `scripts/setup.py` 里的 PAGE。

**agent 验证**（2026-10-08 实测通过）：
1. setup.py 的 stdout 输出 `{"ok": true, "uin": ...}`。
2. 运行 `python {baseDir}/scripts/doctor.py`，期望结果：`ok: true`；dnspod / teo / ssl / lighthouse / tat / domain 均为 allowed；finance 为 denied。

**向导会拦下并用大白话提示用户的情况**（均已实测）：
- 格式不对
- SecretId 错误或已删除
- SecretKey 错误
- 用户填的是主账号密钥（会拒绝，并建议用户禁用这个主账号密钥）
- 子账号没有挂策略

**常见卡点**：
- 粘贴策略时报"策略语法错误"：多半是没有先删掉框里原有的内容。
- 页面打不开：先确认 setup.py 还在运行（默认 30 分钟后超时退出），然后重新运行一次。

## C0-远程：agent 和用户不在同一台电脑上（agent 跑在云端或服务器上）

这种情况下网页向导用不了，用户的浏览器访问不到 agent 所在机器的 127.0.0.1。按以下顺序选择：

1. **平台提供密钥或环境变量设置**（大多数云端 agent 平台都有）：请用户把 SecretId、SecretKey
   分别填进平台的 secret 设置，变量名为 `TENCENTCLOUD_SECRET_ID` 和 `TENCENTCLOUD_SECRET_KEY`。tcapi 会自动读取。
   建策略、建子用户的步骤，把 setup.py 页面里第 1–3 步的文字原样发给用户。
2. **平台没有这类设置**：先如实告诉用户这个限制，由**用户自己决定**是否把密钥发到对话里。不要主动索要。
   - 要说清楚的事：密钥会留在对话记录里；它的权限有限（花不了钱、删不了服务器、看不到实名资料）；
     如果担心，随时可以在控制台禁用 agent-ops，再重新给一对新密钥。
   - 用户同意并发来后，立即调用 `tcapi.save_credential()` 保存，之后长期使用。不要在回复里复述密钥。
   - 不要让用户"用完就轮换"，否则 agent 就无法继续长期工作。只有确认泄露时才轮换。

## C1 买 EdgeOne 套餐（R2）/ C2 买 Lighthouse（R3）/ C3 备案

- **C2 买服务器**：不要手写卡片，直接用 `python {baseDir}/scripts/buy_server.py plan` 输出的 `card` 字段。
  它带预选好的购买链接和实时价格，同时要在后台运行 plan 输出的 `wait_cmd`，自动检测购买完成。
- C1（EdgeOne）和 C3（备案）的卡片内容，见 `routes.md` 中对应路径的「人工卡」段落。
注意：开防火墙端口**不需要**人工卡，agent-ops 可以自己调用 `CreateFirewallRules`。

## C4 买域名

agent 先用 API 查好候选（见 routes.md R0），然后一次性发出：

```
🧑 需要你买一个域名（约 5 分钟；第一次买还要等实名审核 1–3 个工作日）
我查过了，这几个可以注册（价格是腾讯云实时报价，首年/续费）：
  1. xxx.com   ¥83 / ¥90
  2. xxx.cn    ¥33 / ¥38
  3. …
建议：<一句话理由，比如面向海外用 .com、面向国内用 .cn 更便宜>

入口：https://buy.cloud.tencent.com/domain  搜索域名 → 立即加购 → 选年限 → 选信息模板 → 支付
⚠️ 下单时必须选一个「已通过实名审核」的信息模板。没有的话，先去建一个：
   https://console.cloud.tencent.com/domain/template （个人用身份证，企业用营业执照）。
   审核要 1–3 个工作日，通过之后才能下单。所以这一步越早做越好。
⚠️ 审核通过之前，注册局会暂停解析（ServerHold），网站打不开，这属于正常现象。
   审核通过后 1–2 个工作日恢复。
   是否开启自动续费由你决定：域名过期后被别人抢注，就很难再拿回来。

买好后回我域名，我来配置解析。
```

**agent 验证**：执行 `dnspod DescribeDomainList`，确认新域名已经出现在账号里。
如果没出现，执行 `domain DescribeDomainNameList` 查看注册状态。

## human_op 通用卡（被策略拒绝的操作）

tc_error 返回 `kind: human_only` 时使用：说明要做什么、为什么需要人来做（付费或不可逆），
给出控制台直达链接和具体参数（实例 ID、套餐、时长）。人做完后，agent 用对应的 Describe 接口确认。
