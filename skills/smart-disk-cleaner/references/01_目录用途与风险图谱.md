# 目录用途与风险图谱

> 通用参考。用于在扫描出候选项目后，快速判定"这是什么、能不能删"。
> 判定不确定时，**一律归入"需确认"**，不许猜测。

## 风险分级定义

| 级别 | 含义 | 处理方式 |
|---|---|---|
| **低** | 纯可再生缓存。删除后应用自动重建，仅首次加载略慢 | 可列入默认清理，写入规则库后下次免问 |
| **中** | 会丢失使用痕迹或需重新配置（登录态、偏好、历史记录） | 逐项告知后果，获确认后删 |
| **高** | 含不可再生的用户数据或程序本体，删除即永久损失或功能损坏 | **默认保留**。仅在用户明确指名后处理 |
| **禁** | 删除会导致系统崩溃或违反数据安全 | 任何情况下不处理，仅说明 |

## Windows

| 路径 | 用途 | 风险 | 说明 |
|---|---|---|---|
| `C:\Windows\Temp` | 系统临时文件 | 低 | 部分文件被占用删不掉，属正常 |
| `C:\Windows\SoftwareDistribution\Download` | Windows 更新下载缓存 | 低 | 需管理员；删后无法回滚已装更新 |
| `C:\Windows\WinSxS` | 组件存储（旧版本系统文件） | **禁手动** | 只能 `Dism /Online /Cleanup-Image /StartComponentCleanup` |
| `C:\Windows\Installer` | MSI 安装包缓存 | 高 | 删后程序无法卸载/修复 |
| `C:\Windows\Prefetch` | 程序启动预读数据 | 低 | 删后短期内程序启动变慢 |
| `C:\hiberfil.sys` | 休眠文件，约等于内存 75% | 中 | `powercfg -h off` 关闭，同时禁用快速启动 |
| `C:\pagefile.sys` | 虚拟内存 | 中 | 一般不动；可调小但影响多任务稳定性 |
| `C:\$Recycle.Bin` | 回收站 | 低 | 不清空则删除不释放空间 |
| `C:\Recovery` / `C:\SWSetup` | 厂商恢复/驱动源 | 高 | 厂商预装恢复介质 |
| `C:\Windows.old` | 旧系统备份 | 中 | 升级后 10 天内可回滚，之后可删 |

## 应用缓存与数据

| 路径 | 用途 | 风险 | 说明 |
|---|---|---|---|
| `%LOCALAPPDATA%\npm-cache` | npm 包缓存 | 低 | 可再生；重装依赖时需联网 |
| `%LOCALAPPDATA%\pnpm-cache` / `Yarn` | pnpm / Yarn 缓存 | 低 | 同上 |
| `%LOCALAPPDATA%\pip` | pip wheel 缓存 | 低 | 同上 |
| `%LOCALAPPDATA%\go-build` | Go 编译缓存 | 低 | 下次编译变慢 |
| `%APPDATA%\npm\node_modules` | **全局 npm 包本体** | **高** | 含 pnpm 等命令，删则命令行工具失效 |
| `%LOCALAPPDATA%\Google\Chrome\User Data\*\Cache` | Chrome 网页缓存 | 低 | 不影响书签密码 |
| `%LOCALAPPDATA%\Microsoft\Edge\User Data\*\Cache` | Edge 网页缓存 | 低 | 同上 |
| `%LOCALAPPDATA%\Microsoft\Windows\INetCache` | WebView / IE 缓存 | 低 | 同上 |
| `%LOCALAPPDATA%\Microsoft\Windows\Explorer\thumbcache_*.db` | 缩略图缓存 | 低 | 删后图片文件夹首开慢一两秒 |
| `%LOCALAPPDATA%\CrashDumps` | 崩溃转储 | 低 | 正在排查崩溃时才有价值 |
| `%LOCALAPPDATA%\Microsoft\Terminal Server Client\Cache` | 远程桌面位图缓存 | 低 | 可再生 |
| `%LOCALAPPDATA%\Packages` | UWP 应用数据 | 高 | 含已装应用运行数据 |
| `%LOCALAPPDATA%\Docker` | Docker 镜像与容器数据 | **禁手动** | 通过 `docker system prune` 处理 |
| `%LOCALAPPDATA%\wsl` | WSL 子系统数据 | 高 | 含 Linux 环境本体 |
| `%LOCALAPPDATA%\Programs\Python` | Python 解释器 | **高** | 删则所有 Python 项目失效 |
| `%LOCALAPPDATA%\ms-playwright` | 浏览器自动化内核 | 低 | 可再生（`playwright install`） |
| `%LOCALAPPDATA%\Temp` | 用户临时目录 | **中** | **必须先扫业务文件**，常混有解压资料 |
| `%LOCALAPPDATA%\Microsoft\OneDrive\logs` / `Update` | 云盘日志与更新包 | 低 | 需管理员 |

## 开发环境

| 路径 | 用途 | 风险 | 说明 |
|---|---|---|---|
| `%LOCALAPPDATA%\微信开发者工具` | 已安装软件 | 中 | 安装型，迁移会失效，只能留或卸载 |

## 高敏类别（永不写入固定规则）

以下位置**不进入自动清理范围**，每次都必须回到四要素确认流程：

1. 用户个人库：`Documents` / `Downloads` / `Desktop` / `Pictures` / `Videos` / `Music`
2. 聊天与通讯数据：微信 / QQ / 钉钉 / 飞书 的聊天记录与收件文件
3. 财务与法务：合同、财报、发票、工商变更（含"股权变更材料"类）、税费申报
4. 项目工作底稿：任何含 `.xlsx` / `.docx` / `.pdf` / `.dwg` / `.psd` 的自定义目录
5. 已安装程序本体：`Program Files`、`%LOCALAPPDATA%\Programs` 下的应用目录

## 判不准时的启发式判断

看该目录里有没有这些文件——**有就是程序本体，不是缓存**：

- `.exe` / `.dll` → 可执行程序
- `node_modules` → JS 依赖树
- `packages` → Python/Agent 依赖
- `.vhdx` / `.vmdk` → 虚拟机磁盘
- `.msi` / `.msp` → 安装包
- `.safetensors` / `.bin` / `.gguf` → 模型权重（大但可能下载代价高）
