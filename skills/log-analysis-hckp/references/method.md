## 适用场景
出故障不知道看哪。

## 核心方法
先聚合错误率，再定位异常，最后溯源。

## 标准步骤
1. 集中收集日志
2. 按级别/接口聚合错误
3. 定位突增时间点
4. 关联部署与变更
5. 沉淀为告警规则

## 可直接套用的模板
```
收集→聚合ERROR率→定位尖峰→关联变更
```

## 常见错误
- 日志散落
- 只看报错不看趋势
- 不复盘
