⚡性能优化

定位 CPU / 内存 / 磁盘的真实瓶颈，给出可直接执行的调优值。

展开细节
  • 磁盘队列、%Disk Time、换页速率采样判读
  • 后台预读 / 索引 / 无用服务识别
  • 内核参数与文件句柄上限调优（给具体数值）
  • 按内存占用排序进程，区分正常吃内存与泄漏
🛡安全体检与加固

账户、防火墙、补丁、暴露面全面核查，并生成可回滚的加固脚本。

展开细节
  • 口令策略、锁定阈值、权限扩散、空口令账户
  • 防火墙 / SMBv1 / RDP / SSH / UAC / 补丁基线
  • 数据库与缓存端口暴露面识别
  • 加固脚本 + 回滚脚本，改前自动打配置快照
🦠病毒木马后门

从持久化、落地样本、提权后门三条线排查，并给出清除顺序。

  • cron、systemd、ld.so.preload、SSH 公钥后门
  • 临时目录落地样本、SUID 提权后门、内存马特征
  • 强调先取证再清除，避免破坏证据
🧹硬盘瘦身

只读扫描找出空间去哪了，按风险分级，清理先进隔离区可还原。

展开细节

🖥远程 Linux / UNIX

SSH 下发只读探针，目标机不留任何文件；UNIX 也能跑。

2诊断结论

木马 / 病毒深度查杀

全流程只读：不结束进程、不删文件、不改配置。处置动作一律先生成脚本，审阅后手动执行。
查什么：挖矿（持续高 CPU 进程 · 矿池通信 · DNS 缓存痕迹）、Webshell （PHP/JSP/ASP/ASPX 特征评分）、勒索（勒索信 · 批量加密扩展名）、 隐藏持久化（WMI 事件订阅 · 粘滞键后门 · BITS 任务）。 判定走证据链，单项证据不足只提示不定罪。
