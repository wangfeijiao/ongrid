# 常见错误类型与排查修复指南

根因推理时对照本目录。每条给出「常见根因」与「排查动作 → 修复方案」。
领域专属的错误（Nginx / Kubernetes / MySQL）请优先查对应领域文件。

## 1. 连接类（Connection）

| 错误特征 | 常见根因 | 排查 → 修复 |
|----------|----------|-------------|
| `connection refused` | 目标服务未启动 / 端口错 / 防火墙拒绝 | 查进程与端口监听 → 启动服务、改端口、放行防火墙 |
| `connection timeout` / `timeout` | 网络抖动 / 目标过载 / 连接池耗尽 | 查目标负载与延迟 → 扩容、优化目标、调大连接池 |
| `connection reset` | 服务端主动断开 / LB 超时 | 查服务端为何断开 → 调大 LB 超时、修复服务端 |
| `broken pipe` | 对端已关闭仍写 | 查对端生命周期 → 加心跳、处理对端关闭 |

## 2. 资源类（Resource）

| 错误特征 | 常见根因 | 排查 → 修复 |
|----------|----------|-------------|
| `out of memory` / `OOM` | 内存泄漏 / 大对象 / 堆过小 | 查内存曲线、dump 堆 → 修复泄漏、调大堆 |
| `too many open files` | 文件句柄泄漏 | 查 fd 数 → 关闭泄漏句柄、调大 `ulimit -n` |
| `connection pool exhausted` | 连接池过小 / 连接未归还 | 查连接占用 → 调大池、修复连接泄漏 |
| `disk full` / `no space` | 磁盘写满 | 查磁盘占用 → 清理、配置日志轮转 |

## 3. 空值与类型（Null / Type）

| 错误特征 | 常见根因 | 排查 → 修复 |
|----------|----------|-------------|
| `NullPointerException` / `NoneType` / `nil pointer` | 未判空的返回值 / 未初始化字段 | 定位空值来源 → 加判空或默认值 |
| `TypeError` / `ClassCastException` | 类型不匹配 | 查数据来源类型 → 做类型转换或校验 |
| `IndexOutOfBounds` / `IndexError` | 越界访问 | 查边界条件 → 修正循环范围/判空 |

## 4. 并发与锁（Concurrency）

| 错误特征 | 常见根因 | 排查 → 修复 |
|----------|----------|-------------|
| `deadlock` / `Deadlock found` | 加锁顺序不一致 | 查锁获取顺序 → 统一顺序、缩小临界区 |
| `lock wait timeout` | 长事务持有锁 | 定位长事务 → 缩短事务、优化加锁 |
| 数据不一致 / `race condition` | 未加锁的共享状态 | 查并发写入 → 加锁或改并发安全结构 |

## 5. 数据库（Database）

| 错误特征 | 常见根因 | 排查 → 修复 |
|----------|----------|-------------|
| `query timeout` / `Slow Query` | 缺索引 / 全表扫描 / 大表 join | 看慢查询日志 → 加索引、优化 SQL |
| `duplicate key` / 唯一约束冲突 | 重复写入 / 幂等缺失 | 查写入路径 → 加幂等处理 |
| `foreign key constraint` | 删除顺序错误 / 孤儿数据 | 查外键依赖 → 调整删除顺序 |

## 6. 业务与外部依赖

| 错误特征 | 常见根因 | 排查 → 修复 |
|----------|----------|-------------|
| `insufficient balance` | 业务校验 / 并发扣款未加锁 | 查幂等与并发 → 加锁/幂等 |
| `unauthorized` / `401` / `403` | Token 过期 / 权限错误 | 查鉴权配置 → 修权限、调 Token 有效期 |
| `404` | 路由未注册 / 资源不存在 | 查路由与资源 → 注册路由、修 ID |
| `500` | 服务端未捕获异常 | 查对应接口完整堆栈 → 加异常处理 |

## 7. 突增类信号（结合时间线判断）

| 信号 | 判断 | 动作 |
|------|------|------|
| 某时段错误量突增 | 变更/发布引入，或外部依赖故障 | 查该时段变更记录 |
| 错误持续稳定 | 慢性问题（泄漏/配置错） | 看长期趋势 |
| 周期性突增 | 定时任务/流量高峰 | 查定时任务与容量 |

---

## 根因推理输出格式

```
[模式] 高频模式摘要
[类型] 错误类别（连接/资源/空值/并发/DB/业务）
[根因] 最可能根因（1-2 个，按可能性排序，标注为推断）
[证据] 支撑数据（频次、时间分布、来源）
[修复] 具体可执行的修复方案（改了哪里、怎么改）
```
