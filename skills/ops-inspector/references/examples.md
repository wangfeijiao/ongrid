# 输入输出示例

## 示例 1：整体基本健康（关注磁盘）

用户输入：
检查一下 10.0.0.5 这台服务器

技能输出：

结论：服务器整体基本健康，根分区磁盘剩余空间偏低，建议纳入观察。

指标明细：

| 指标 | 当前值 | 阈值 | 状态 |
| --- | --- | --- | --- |
| CPU 使用率（持续） | 12% | 关注 70% | 正常 |
| CPU iowait | 1% | 关注 10% | 正常 |
| 平均负载 / 核数（15 分钟） | 0.3 | 关注 0.7 | 正常 |
| 内存 available | 55% | 关注 20% | 正常 |
| swap 使用率 / 活动 | 0% / 无 | 关注 10% | 正常 |
| 磁盘使用率（/） | 82% | 关注 80% | 关注 |
| 磁盘剩余空间（/） | 8.4GB | 关注 10GB | 关注 |
| inode 使用率 | 31% | 关注 80% | 正常 |
| D 状态 / 僵尸进程 | 0 / 0 | 无 | 正常 |
| 错误日志 | 无 | 无 | 正常 |

风险项：

- 根分区使用率 82%、剩余 8.4GB（证据：df -hT / 输出），双条件均达关注线。按当前增长速率约 2 个月后触及 90% 危险线（置信度：中）。

建议：

1. 清理 /var/log 下 30 天前日志归档与旧安装包（低风险，先 df 确认目标再执行）。
2. 检查是否有大文件占用：du -x -h --max-depth=1 / 定位。
3. 一周后复查，确认增长速率。

待确认项：无。

## 示例 2：服务异常

用户输入：
nginx 连不上了，帮我看看

技能输出：

结论：nginx 服务当前未运行，最近一次退出原因指向配置语法错误，属于启动失败型故障。

指标明细：

| 指标 | 当前值 | 阈值 | 状态 |
| --- | --- | --- | --- |
| nginx 进程 | 无 | 应运行 | 危险 |
| 80 端口监听 | 无 | 应监听 | 危险 |
| systemctl 状态 | failed | active | 危险 |
| 系统资源 | CPU 8%，内存 available 60% | 正常 | 正常 |

风险项：

- nginx 单元状态为 failed（证据：systemctl status nginx），最近日志包含 configuration file test failed 提示（证据：journalctl -u nginx -p err，置信度：高）。

建议：

1. 先只读定位：nginx -t 查看具体语法错误行（不改动任何文件）。
2. 按错误行修复配置文件后，由用户确认后执行 systemctl restart nginx。
3. 验证：ss -tlnp 确认 80 端口恢复监听。

待确认项：配置文件最近是否被修改过（可能是最近发布导致）。

## 示例 3：负载高但 CPU 空闲（磁盘 IO 瓶颈）

用户输入：
服务器很卡，top 看 CPU 不高但负载很高，怎么回事

技能输出：

结论：负载高而 CPU 用户态占用低，关联判断指向磁盘 IO 瓶颈：iowait 持续高位且有 D 状态进程堆积，最可能根因是磁盘 IO 延迟过高。

指标明细：

| 指标 | 当前值 | 阈值 | 状态 |
| --- | --- | --- | --- |
| 平均负载 / 核数（15 分钟） | 4.2 / 8 核 = 0.53 | 关注 0.7 | 正常 |
| 平均负载（1 分钟 / 15 分钟） | 8.1 / 2.0 | 1 分钟 > 15 分钟 | 关注（上升中） |
| CPU 使用率（us+sy） | 18% | 关注 70% | 正常 |
| CPU iowait | 41% | 关注 10% | 危险 |
| D 状态进程 | 12 | 无 | 危险 |
| vmstat r / b | 8 / 14 | b > 5 为 IO 等待 | 关注 |

关联判断：

- 负载 1 分钟值（8.1）显著高于 15 分钟值（2.0），负载正在快速累积（证据：uptime）。
- CPU 用户态仅 18% 但 iowait 41%，且 vmstat b 列 14（阻塞进程多），判断瓶颈在磁盘 IO 而非 CPU 或内存（证据：top、vmstat 1 5）。

风险项：

- iowait 41% 远超危险线 30%，伴随 12 个 D 状态进程（证据：ps -eo stat | grep ^D），磁盘响应异常（置信度：高）。

建议：

1. 确认 IO 来源：iostat -x 1 5 查看 await 与 %util，定位慢盘或异常进程（低风险只读）。
2. 检查是否有备份、日志压缩或批量任务在跑，错峰执行（低风险）。
3. 若 await 持续 > 50ms，评估磁盘健康或考虑扩容/迁移（中风险，需业务窗口）。

待确认项：磁盘类型与 RAID 配置；近期是否执行过大文件拷贝或备份任务。
