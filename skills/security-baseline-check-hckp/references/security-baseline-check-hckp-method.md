# 安全基线核查要点

## 一、适用场景

按主机与服务安全基线逐项核查，输出合规率与整改项。

## 二、核心维度与权重

| 维度 | 权重 | 判据 |
|------|------|------|
| 账号安全 | 25 | 口令策略、禁用默认账号 |
| 服务加固 | 25 | 最小化服务与端口 |
| 补丁与更新 | 25 | 及时打补丁 |
| 日志与审计 | 25 | 审计开启与留存 |

## 三、判定标准

1. 须禁用或改密默认账号
2. 仅开放必要端口与服务
3. 高危漏洞须限期修复
4. 审计日志须开启并留存

## 四、参考基准

| 指标 | 参考值 |
|------|--------|
| 口令长度 | ≥12位复杂度 |
| 高危修复时限 | 7天 |
| 日志留存 | ≥180天 |

## 五、交付物结构

1. **合规率总评**
2. **分项核查表**
3. **不合规项**
4. **整改清单**

## 六、使用方式

1. 按维度与判据整理输入，产出 `input.json`（字段见 `SKILL.md`）。
2. 付费取得「安全基线规范包」规范包（含上表结构与基准值）。
3. 运行 `python3 scripts/apply_spec.py --spec security-baseline-check-hckp_spec.json --input input.json --out 交付物.md`。

> 本文件为本地方法论，付费规范包由远端服务按次下发；两者共同构成完整能力。
