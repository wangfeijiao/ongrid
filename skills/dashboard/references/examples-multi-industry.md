# 看板工坊 · 中性行业样例

## 例 1：社区活动运营看板（静态汇报）
- 简报：4 个 KPI（报名数/参与率/满意度/成本）、数据源 CSV、静态汇报。
- 布局：顶部 4 卡片 + 趋势图 + 活动明细表。
- 技术：HTML + Chart.js 一次性渲染。
- 版本：static。

## 例 2：仓库作业监控（分钟级）
- 简报：KPI（在库/吞吐/设备状态）、刷新诉求 1 分钟、数据源 API。
- 布局：顶部 4 卡片 + 吞吐趋势 + 设备状态告警区。
- 技术：Streamlit 定时 rerun 或前端轮询。
- 版本：refresh。

## 例 3：课程平台实时看板（秒级）
- 简报：KPI（在线人数/完课率/告警）、实时、WebSocket 推送。
- 布局：顶部卡片 + 在线趋势（流式）+ 告警流。
- 技术：WebSocket + ECharts，断线重连 + 限流。
- 版本：realtime。

## 例 4：设备运行态势（实时 + 权限）
- 简报：KPI（运行/故障/能耗）、实时、含敏感能耗指标需权限。
- 技术：Grafana 或 WebSocket + 权限网关。
- 版本：realtime（强调权限控制）。
