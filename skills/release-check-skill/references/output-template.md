# 上线检查与回滚方案 · 输出模板与示例

> 配套技能：`release-check-skill`　|　所属应用：Git版本发布助手

## 输出骨架（照此结构填写，方括号为待填内容）

- 上线检查清单（可勾选）
- 发布步骤表
- 回滚方案（含触发条件与可逆性）
- 迭代纪要与监控观察表

## 填写顺序建议

1. 产出上线检查清单：代码 / 配置 / 数据 / 依赖 / 权限 / 备份 / 通知
2. 列发布步骤表（步骤 / 执行人 / 预计耗时 / 验证方式）
3. 写回滚方案：触发条件、回滚步骤、数据可逆性说明
4. 定监控观察窗口与关键指标阈值
5. 整理迭代纪要：结论 / 待办 / 风险

## 交付前逐条打勾

- [ ] 回滚方案含触发条件与数据可逆性判断
- [ ] 检查项均可勾选、责任到人
- [ ] 不含真实密钥、内网地址与账号
- [ ] 观察窗口与指标阈值明确

## 常见坑（出现以下情况请返工）

- 只写回滚命令不写触发条件，出事没人敢拍板
- 数据不可逆却不在方案里说明
- 检查清单过长过泛，上线时没人真的逐条看

## 触发词（用于自查是否命中技能）

- 上线检查清单
- 发布前要确认什么
- 回滚方案怎么写
- 发布流程
- 迭代纪要
- 上线检查清单怎么搭框架
- 有没有上线检查清单的现成模板
- 帮我出一版上线检查清单
- 帮我列个清单
- 做个表格
- 有没有核对表
- 帮我分析一下
