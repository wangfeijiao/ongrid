## 适用场景
发布靠手工易出错。

## 核心方法
自动构建测试，部署分级可回滚。

## 标准步骤
1. 提交触发自动构建
2. 跑单元/集成测试门禁
3. 制品版本化
4. 分级部署（灰→全）
5. 一键回滚预案

## 可直接套用的模板
```
commit→build→test门禁→artifact→灰度→全量→回滚
```

## 常见错误
- 无测试门禁
- 直接全量
- 无回滚

## 自检清单
- [ ] 有测试
- [ ] 有灰度
- [ ] 可回滚
