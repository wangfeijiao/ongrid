## 适用场景
怕资源不够或浪费。

## 核心方法
看历史趋势，按峰值+增长预留。

## 标准步骤
1. 收集资源历史使用
2. 算增长率与季节性
3. 定峰值冗余（如 30%）
4. 给采购/扩容时点
5. 建预警阈值

## 可直接套用的模板
```
历史增长X%/月｜峰值冗余30%｜预警85%｜扩容时点T
```

## 常见错误
- 按均值不留余
- 忽略峰值
- 不预警
