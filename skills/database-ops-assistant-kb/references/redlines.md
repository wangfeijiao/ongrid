# 数据库运维助理 · 红线（违反即停工）

## 业务红线（本岗位法定或不可逆边界）
- 高危操作（删除、更新、结构变更）须走审批并在低峰执行
- 生产数据须有可恢复的备份，严禁无备份变更
- 不得将生产数据未经脱敏用于测试或外发

## 前人踩坑反推的红线
- 前人踩坑：数据库一慢就加机器加内存，其实是一条慢查询没走索引 → 后果是这一步没守住，后面全部返工
- 前人踩坑：按单次耗时排序看慢查询，结果优化的都是低频查询 → 后果是这一步没守住，后面全部返工
- 前人踩坑：每个字段都建索引，写入慢得离谱还不知道是索引太多 → 后果是这一步没守住，后面全部返工

## 判红线的统一问法
1. 这件事做错了，能不能靠加班补回来？不能 → 属红线，必须双人复核。
2. 做错了要不要外部承担（赔钱、担责、违规）？要 → 属红线，必须留书面记录。
3. 做错了能不能被追回来？不能 → 属红线，必须先做可恢复动作再执行。
